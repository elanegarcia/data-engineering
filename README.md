# Data Engineering

Criei este repositório para reunir projetos práticos de Engenharia de Dados, explorando desde ingestão e transformação até modelagem, qualidade, orquestração e disponibilização de dados em ambientes cloud.

O objetivo é documentar minha evolução na área e, principalmente, demonstrar na prática a construção de soluções de dados escaláveis, confiáveis e bem estruturadas.

## Sobre o repositório

Os projetos deste portfólio vão abordar diferentes etapas do ciclo de Engenharia de Dados, incluindo:

- Pipelines ETL e ELT
- Ingestão e transformação de dados
- Modelagem de dados
- Data Quality
- Orquestração de workflows
- Processamento distribuído
- Processamento batch e streaming
- Data Lake e Data Warehouse
- Arquiteturas de dados em cloud
- Monitoramento e observabilidade
- Infraestrutura como código
- CI/CD aplicado a dados
